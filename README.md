# Physical Drum Engine V1.1

Original physical-response drum sampler/resynthesis instrument built with JUCE.

## Current build
- AU + VST3 + Standalone
- MIDI drum instrument
- 12 mapped pads
- Per-pad WAV loading
- Factory snare embedded into the plugin bundle
- Velocity-driven gain, pitch, transient/body balance and decay
- Humanization/variation/timing controls
- Universal macOS build target (Apple Silicon + Intel)

### Default MIDI notes
Kick 36, Snare 38, Closed Hat 42, Open Hat 46, Tom 1 45, Tom 2 43, Tom 3 41, Crash 49, Ride 51, Clap 39, Perc 1 37, Perc 2 40.

This is an original implementation and does not copy proprietary code or factory content from other drum products.
